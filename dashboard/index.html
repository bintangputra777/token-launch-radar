How the radar works

The board

The board ranks protocols that record no token: no market cap, no CoinGecko id, no symbol in the snapshot. It also leaves out wrapped, staked and bridged products of a token that already trades — the watchlist’s own rule, applied to the whole universe instead of only above the floor. A category of Bridge, Canonical Bridge, Liquid Staking, Liquid Restaking, Restaked BTC or CEX is out; a name carrying a whole word wrapped, staked or staking is out; a name beginning with an exchange’s name is out; a name ending in a version marker is out. That rule removes 144 of the snapshot’s 342 pre-token protocols, including 39 of the 160 early rows a looser rule would have kept. The snapshot carries no parent-protocol field, so the house’s parent rule cannot be applied from these bytes: 20 rows sit above the floor but outside the watchlist for that reason, and the detail view flags them.

The value model (radar-2)

Implied value = TVL × 0.25 × growth × maturity × breadth. Growth is the seven-day TVL change clamped to −60…+120%, weighted 0.5: growth = 1 + (change ÷ 100) × 0.5. Maturity is 0.6 + min(age in days, 1095) ÷ 1095 × 0.4; a protocol with no listing date is scored at 365 days. Breadth is 1 + 0.05 × min(chains − 1, 4): a protocol on more chains has more surfaces to farm. The same function scores every row — no protocol name is special-cased — and the detail view recomputes each row live from the same constants, so the page and board.json always agree. The model sandbox below lets you change the constants and watch the board re-rank; it changes only this page, never board.json.

The farm plan

Every row carries seven steps derived from its own record: its category sets the action, its TVL sets the capital, its age sets the hold, its chains set the spread. Each step states what it costs and how long it takes. Step three tells you to check the protocol’s own site for a points program — the radar does not know whether one exists. Nothing here is a promise: a pre-token protocol may never issue a token, and farming costs gas whether or not an airdrop comes.
